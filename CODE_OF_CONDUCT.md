# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part is expected to follow it.

## Scope

The Code of Conduct applies in all project spaces: issues, pull requests, discussions and any other project communication channel.

## Reporting

Report unacceptable behaviour to the project maintainers. Reports are reviewed and investigated promptly and fairly.
